🎯 Objetivo

Problema: acumulación de desechos en calles y camiones que pasan en horarios irregulares. Impacto: contaminación del suelo, drenajes tapados en lluvias y focos de infección. Solución: conectar a los ciudadanos con el servicio de limpieza mediante alertas, reportes con GPS, rutas eficientes y códigos QR.

🌍 Google Maps

Para usar el mapa de Google Maps (el mismo del celular) hace falta una clave de API de Google. Crearla es gratis, pero Google pide activar la facturación en su consola (tiene uso gratuito mensual; revisa sus precios vigentes).

  1. Entra a console.cloud.google.com y crea un proyecto.
  2. Activa Maps JavaScript API y la facturación.
  3. Credenciales → Crear clave de API; restríngela a tu sitio (por ejemplo http://localhost:8000/*).
  4. Pégala aquí (modo autoridad).

🔐 Autoridad, compartir y exportar

Solo el personal del municipio puede marcar reportes como atendidos, borrarlos y editar zonas. Con el servidor en línea se entra con la clave de administrador; sin servidor, con un PIN que se guarda solo en este dispositivo.
